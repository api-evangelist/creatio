# Creatio

> Creatio is an AI-native no-code platform for CRM and workflow (business process) automation, spanning Sales, Marketing, and Service Creatio plus the Studio Creatio no-code platform. Its APIs expose platform data and processes over OData 4 (recommended), legacy OData 3, and the RESTful DataService web service, with forms (cookie) or OAuth 2.0 authentication. This llms.txt was generated by the API Evangelist enrichment pipeline from the public developer documentation.

## APIs

- [OData 4 API](https://academy.creatio.com/docs/developer/integrations_and_api/data_services/odata/overview): Read/write platform entities via the OData 4 service at /0/odata; $metadata (EDMX) at /0/odata/$metadata.
- [DataService API](https://academy.creatio.com/docs/developer/integrations_and_api/data_services/dataservice/overview): RESTful data access via InsertQuery / SelectQuery / UpdateQuery / DeleteQuery / BatchQuery.
- [Business Process service](https://academy.creatio.com/docs/developer/integrations_and_api/business_process_service): Run and interact with Creatio business processes over HTTP.

## Authentication

- [Authentication basics](https://academy.creatio.com/docs/developer/integrations_and_api/authentication/authentication_basics/overview): Forms (cookie) auth via AuthService.svc (BPMCSRF, ForceUseSession), OAuth 2.0, Basic, Anonymous.
- [OAuth 2.0 setup](https://academy.creatio.com/documents?id=2396): OAuth 2.0 client-credentials authorization via the Creatio Identity Service.
